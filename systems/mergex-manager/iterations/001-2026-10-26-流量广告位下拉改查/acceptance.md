# 验收标准

结果先写未测。做完验收后再改。

| 编号 | 对应用例 | 谁、做什么、必须看到什么 | 结果 |
|---|---|---|---|
| AC-01 | TC-01 | 在 ADX 报表和鲲鹏报表的流量广告位里输入一个 ID 片段。两处下拉都只出现包含这段的流量广告位 ID，同一个 ID 只有一行，不出现广告位 ID 前缀。输入两个完整 ID 时按精确匹配 | 豁免：用户确认「不需要测试验证了，或者简单验证一下即可」；残余风险是没有在已登录页面上输入关键字点选 |
| AC-02 | TC-02 | 在 ADX 报表选中一个供应商，搜索框留空。下拉只列出这个供应商的流量广告位 ID，并自动发起查询 | 豁免：用户确认「不需要测试验证了，或者简单验证一下即可」；残余风险是没有在页面上改选供应商看下拉 |
| AC-03 | TC-03 | 不选供应商、也不输入。下拉不发请求。再输入关键字后，按关键字返回 ID，不要求先选供应商 | 豁免：用户确认「不需要测试验证了，或者简单验证一下即可」；残余风险是没有看空条件下拉是否发请求 |
| AC-04 | TC-04 | 在 ADX 报表选中一个流量广告位并查询。请求里的 `trafficPlaceIdList` 只有流量广告位 ID。报表只保留这个 ID 的数据 | 豁免：用户确认「不需要测试验证了，或者简单验证一下即可」；残余风险是没有用 lenovo_store3 在页面上查出表格 |
| AC-05 | TC-05 | 用以前保存的「广告位 ID_流量广告位 ID」去查 ADX 报表。结果和取下划线后面的 ID 再查一致，不是空表 | 豁免：用户确认不再做下划线切开，并确认「不需要测试验证了，或者简单验证一下即可」；残余风险是旧的拼接筛选会按整段去查 |
| AC-06 | TC-06 | 在鲲鹏报表用新搜索选中一个流量广告位后查询。表格不是空的，数字和没选这个 ID 时相同 | 豁免：用户确认「不需要测试验证了，或者简单验证一下即可」；残余风险是没有打开鲲鹏报表核对数字 |
| AC-07 | TC-07 | 刷新后菜单没有「多曝光报表」。直接打开旧地址进不去。查询和下载接口不再可用 | 豁免：用户确认删掉菜单 SQL、后端报表代码不动，并确认「不需要测试验证了，或者简单验证一下即可」；残余风险是菜单还在，前端页面已删，后端查询还在 |
| AC-08 | TC-08 | 映射管理仍能打开并维护流量广告位映射。小时报表不选流量广告位时仍能查出数 | 豁免：用户确认「不需要测试验证了，或者简单验证一下即可」；残余风险是没有打开映射管理和小时报表 |
| AC-09 | TC-09 | 在 ADX 报表先选中一个流量广告位，再改选另一个供应商。已选 ID 还在，下拉里仍能看到它。新列出的 ID 只属于新供应商 | 豁免：用户确认不属于当前供应商的已选要去掉，并确认「不需要测试验证了，或者简单验证一下即可」；残余风险是没有在页面上再选那 3 个供应商看已选是否清掉 |
