# 风险与回退

| 风险 | 影响 | 怎样避免 | 怎样退回 |
|---|---|---|---|
| 菜单 SQL 用太宽的匹配，停掉别的路由 | 别的报表菜单消失 | 先 SELECT，只更新组件名正好是 `FunlinkAnalyse` 的那一条。本轮不执行 | 把这一条的 `status` 改回 `A`。脚本本身用版本管理撤回 |
| 删多曝光时误删共用 SQL 或投影 | 别的报表查不出或编译失败 | 只删名字带多曝光的方法和 SQL。删完跑编译 | 用这一轮提交撤回被删的多曝光代码。没提交前用工作区还原 |
| 放宽 ID 解析后，小时报表收到不带下划线的值也会拿去查 | 小时报表如果以后传纯 ID，行为会和现在丢掉不同。页面这轮不改 | 只改共用解析。不改小时页面。验收时小时报表不传这个条件，确认还能出数 | 恢复成只保留带下划线的值 |
| 鲲鹏选了流量广告位，数字却不变 | 使用者会觉得筛选没生效 | 这是已批准的做法。表里没有这一列，不造一个假筛选。页面仍可选择，查询按其他条件出数 | 把 `trafficPlaceIdList` 加回不支持条件，选中后重新返回空表 |
| 没选供应商时，关键字能看到别的供应商的 ID | 选中后 ADX 可能没有数 | 报表查询仍走原来的供应商权限。这个范围已在需求里写明 | 无代码开关。若要改范围，需要重新审批 |
| 选了供应商且搜索框为空，一次返回全部 ID | 供应商下 ID 很多时下拉会变长 | 对齐包名搜索，这轮不加条数上限 | 无。要加上限需要重新审批 |
| 共享目录里已有别人的未提交改动 | 可能被误改或误算进本轮 | 改产品文件前逐文件记下分支、HEAD 和 dirty。已有改动不覆盖 | 只还原本轮改过的文件 |
| 两个搜索页和 mixin 已经超过 300 行 | 这轮再加代码会让文件更大 | 只加流量广告位那几处。不新开文件，因为新文件不在已批准范围内，改范围会使需求审批失效 | 无。若之后要拆文件，另开一轮或先重批范围 |
