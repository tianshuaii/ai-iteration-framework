# 风险与回退

| 风险 | 影响 | 怎样避免 | 怎样退回 |
|---|---|---|---|
| 平台账号新老接口只改一套 | 不同 `newSwitch` 的账号保存或回显不一致 | 三个 VO 共用同一契约，六个 add/update/get 路径都有定向用例 | 两套接口同步回退新字段，不留半套兼容 |
| 关闭或删除时误伤其他账号/维度 | 策略数据静默丢失 | 所有查询与删除同时携带平台账号维度、`platAccountId` 和 `type=1`，定向测试使用两个账号验证隔离 | 回退该分支代码；测试数据按独立 `policy_id` 恢复，不物理删正式数据 |
| `plat_account_id` 类型或查询维度不一致 | 策略写入但无法回显/导出 | Java 与新老账号 ID 统一用 `Long`，SQL 使用 `BIGINT`；实体、Query、XML、导出和测试同时使用具名维度 | 先回退应用对新维度的读写；只在另行授权的环境操作中评估字段回退，本轮不处理索引 |
| 迁移文件残留索引 DDL | 交付内容违反用户明确的无索引要求 | 对迁移文件执行大小写不敏感的 `index|unique|key` 静态扫描，并在增量 review 中核对只有字段 DDL | 回退误加的索引语句，保留 `plat_account_id` 字段迁移；不对测试库执行 `DROP INDEX` |
| SQL 已交付但环境未迁移 | 新代码在该环境查询新列时失败 | 交付顺序明确为先迁移后发布；本轮不自动执行任何环境 SQL | 未迁移环境不发布新代码；如测试环境已有字段或索引，保留环境现状并另行评估，不在本轮自动回退 |
| 共享 `TrafficDirectionV4` 或列表加载影响旧页 | 连接管理供应商/广告源流量筛选回归 | 原则上只改目标页组装；若必须改共享组件，保持 props 默认值和老调用方不变，并执行 SR-04 | 回退共享组件变更，保留目标页能够独立组装的最小实现 |
| 需求变更后误改广告位 | 范围泄漏，并可能影响预算过滤 | 任务文件不列广告位，实现和 review 都检查产品差异不包含 `EditPlace`、`CreateAdPlaceVo`、`AdPlaceServerImpl` | 立即回退本轮产生的广告位差异，不触碰接管前用户改动 |
| 两个真实仓库已有本地配置改动 | 实现时可能覆盖用户环境 | 保护前端 `build/env/development/adx.js` 和后端 `application.yml` 的接管前 dirty，本轮不编辑、不格式化、不纳入差异 | 本轮不对这两个文件执行回退；如与目标文件意外重叠立即停止 |

## 发布与数据库边界

- 本轮只交付可发布代码和 SQL 文件，不包含迁移、发布、部署、提交或推送授权。
- 实际迁移时必须另行指定测试环境；正式库和正式数据不在本轮授权内。
- 本轮迁移脚本不操作表索引；测试库现有索引的保留或删除需要单独的环境变更授权。
