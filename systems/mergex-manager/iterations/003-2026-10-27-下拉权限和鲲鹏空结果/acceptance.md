# 验收标准

| 编号 | 对应测试 | 标准 | 结果 |
|---|---|---|---|
| AC-01 | TC-01 | 普通用户只传关键字时，新下拉只返回他能看的供应商下的流量广告位 ID | 通过 |
| AC-02 | TC-02 | 传入的供应商里有他不能看的编号时，这些编号不参与查询。交集为空则返回空列表 | 通过 |
| AC-03 | TC-03 | 能看的供应商为空，或三个条件都空，都返回空列表，不扫整张表 | 通过 |
| AC-04 | TC-04 | 鲲鹏列表、趋势、导出在请求带了非空 `trafficPlaceIdList` 时返回空，不返回未过滤的全量 | 通过 |
| AC-05 | TC-05 | 鲲鹏页面不再显示流量广告位，发出的查询里没有这个条件 | 豁免：用户确认「已看过代码了，开始验收」；残余风险：没在已编译页面上再点一次查询，确认请求体 |
| AC-06 | TC-06 | 新下拉的请求字段仍是原来的三个。类型在 `model/vo/traffic/PublisherTrafficPlaceSearchReqVo`，不再是服务接口里的内部类 | 通过 |

结果通常使用“未测”“通过”或“未通过”。只有用户明确确认接受未验证项或残余风险时，才写 `豁免：用户确认……；残余风险……`，不能只写“豁免”“收口”或把没测过的项目写成通过。
