# 决策记录

| 编号 | 决定 | 原因 | 没采用的做法 |
|---|---|---|---|
| D-01 | Admin 用户可见能力最终只保留账户管理；角色页面也删除。 | 用户在 2026-10-26 明确要求“除了账户其他逻辑都删除，只留账户，就连角色也不需要”。 | 继续保留角色、租户或权限管理菜单。 |
| D-02 | 删除账号管理后台的治理审计日志页面及查询接口。 | 用户明确要求删除审计日志页面、代码和接口。 | 仅隐藏菜单但保留可访问路由与查询接口。 |
| D-03 | 密码存库以 `mergex-manager` 当前源码为事实参考。 | 用户点名该项目；源码确认其格式为自定义 48 字符随机盐 MD5。 | 凭名称猜测为普通 MD5，或修改参考项目。 |
| D-04 | 彻底删除角色、租户、路由、权限、授权关系等非账户治理模型、接口和数据表，并同步重构 SSO、BFF、ForwardContext 与 Portal 依赖。 | 用户对 Q1 选择 A。 | 只隐藏 Admin 页面但继续保留后台治理模型。 |
| D-05 | 新设与修改密码采用 48 字符随机盐 MD5；不兼容已有 Argon2，允许旧密码失效并通过重新设密恢复；不复制浏览器 RSA 传输层。 | 用户明确表示“不考虑账号密码失效”，即接受不兼容旧哈希；RSA 与存库格式没有必然关系。 | 双格式校验、懒迁移，或把 RSA 一并复制。 |
| D-06 | 删除治理审计页面、查询 RPC、Dashboard 计数和无意义治理写入；保留 BFF 登录、代理、请求查询与实时日志。 | 用户对 Q3 采用推荐方案。 | 删除全部安全审计和运行日志。 |
| D-07 | 前后端密码最小长度统一为 8 位。 | 用户对 Q4 采用推荐方案。 | 继续沿用 Admin 原有 6 位下限。 |
| D-08 | 保留 Portal 登录与账户信息合约，删除动态路由/权限计算，授权结果稳定返回空集合。 | 用户对 Q5 采用推荐方案；可让调用方在旧合约退场期避免直接 500。 | 连 Portal 通道一起删除，或保留已废弃的动态授权模型。 |
| D-09 | 删除账户层级、创建者和更新操作者关系字段及账户关系图；账户保留自身属性、`yn` 与普通时间戳。 | 用户对 Q6 采用推荐方案；角色和租户删除后这些关系不再承载有效授权语义。 | 继续保留 `parentId`、`creatorAccountId` 等历史治理关系。 |
| D-10 | 48 字符格式的 16 位数字盐由 Node `crypto` 生成，不复刻 `java.util.Random`。 | 用户对 Q7 采用推荐方案；不改变存库格式，同时避免复制弱随机源。 | 为逐实现一致而复制 Java 弱随机盐。 |
| D-11 | 旧密码全部失效后，通过环境变量或一次性运维参数先重设超级管理员，再由其在账户页重设其他账号；初始密码不硬编码、不写入仓库文件。 | 用户对 Q8 采用推荐方案。 | 在源码、seed 默认值或仓库文档中保存公共初始密码。 |
| D-12 | 账户类型只保留 `SUPER_ADMIN`、`PLATFORM_STAFF`；租户类型迁为 `PLATFORM_STAFF` 并删除 `tenantId`。仅 `SUPER_ADMIN` 可进入 Admin 与 BFF 网关管理，`PLATFORM_STAFF` 只保留 Portal 与普通代理。 | 用户确认 Q9 采用推荐方案；删除角色后必须以单一权威字段维持最小权限。 | 保留无租户实体支撑的租户类型，或让 `PLATFORM_STAFF` 继续进入管理端。 |
| D-13 | 账户以 `yn` 软删除，用户名跨所有历史记录永久唯一；删除后不可复用，本轮不新增恢复页面。 | 用户确认 Q10 采用推荐方案；避免历史日志、Session 和身份归属混淆。 | 只检查活动账户并允许复用已删除用户名。 |
| D-14 | 允许多个 `SUPER_ADMIN`；仅超级管理员可创建两类账户；账户类型创建后不可改；禁止自禁用/自删除，并保证至少一个启用的超级管理员。 | 用户确认 Q11 采用推荐方案；兼顾可恢复性与最低管理权限。 | 只允许单个超级管理员，或允许最后一个超管被禁用/删除。 |
| D-15 | 密码重设、账号禁用或软删除立即吊销目标账号全部 Session；本次上线统一吊销全部旧 Session。 | 用户确认 Q12 采用推荐方案；身份与密码模型变化后不能继续信任旧会话。 | 只等 Session 自然过期，或保留迁移前旧会话。 |
| D-16 | 账户页按精简字段定稿：列表和筛选只使用账户自身属性；新增含账号、双次密码、昵称、类型和状态；编辑不允许修改账号或类型；重设密码独立弹窗；保留编辑、启停、重设密码和软删除操作。 | 用户确认 Q13 采用推荐方案；设计树已无未决分支。 | 继续沿用创建者、父级、角色、租户字段，或把重设密码混在普通编辑里。 |
