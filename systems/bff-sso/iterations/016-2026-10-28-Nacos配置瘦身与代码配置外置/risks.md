# 风险与回退

| 风险 | 影响 | 怎样避免 | 怎样退回 |
|---|---|---|---|
| 把仍被消费或没有默认值的键当成冗余删除 | 对应服务启动失败或运行行为漂移 | 每个键同时检查远端值、Schema、代码消费者和测试；必填项单独做缺失测试 | 恢复本地模板和发布前 Nacos 正文，重新构建/启动 |
| 把业务应用名和 Nacos 注册名错误合并 | 服务注册、发现或日志标识改变，跨服务调用失败 | 只合并同义且同值项；BFF 等语义不同项分别保留，测试最终注册参数 | 恢复原服务名键与回退链，回滚对应 Data ID |
| 登录限流默认值或单位变化 | 用户被过早锁定或限流失效 | 使用秒为统一单位，默认值与原常量逐项等价，覆盖边界做定向测试 | 恢复原常量消费并撤回新增远端键 |
| Session/运行时缓存配置非法或过激 | 权限缓存刷新异常、缓存膨胀或跨实例发布超时 | Zod 正整数和上下界校验，模板使用原默认，非法值启动失败 | 删除覆盖键回到代码默认；必要时回滚代码 |
| 六份远端配置在实施期间发生漂移 | 删除清单基于过期事实，覆盖他人修改 | T-01 和发布前比较 revision；变化即停止并重新盘点 | 不发布；若已发布则用本次发布前正文恢复 |
| Nacos 多 Data ID 发布不是事务 | 部分服务使用新契约、部分仍是旧配置 | 逐份发布和验证，批次间设置停止点；test 全链路成功后才进入 dev | 回滚当前批次已发布的 Data ID，验证全部恢复到发布前摘要 |
| test BFF 缺少平台主密钥或登录响应上限 | 测试环境无法启动或安全边界不一致 | T-01 明确来源；发布前按强类型契约补齐，不从文档或代码生成真实密钥 | 恢复 test 原正文并保持发布阻塞，等待正确密钥来源 |
| 敏感值进入文档、测试快照或命令输出 | 凭证泄露 | 证据只存键名/revision/哈希，读取工具输出脱敏；回滚正文放受控临时位置 | 立即停止，删除泄漏副本并按凭证流程轮换；文档只保留事件说明 |
| BFF 原仓库已有未跟踪 `CODE_REVIEW.md` | 用户文件被覆盖或误提交 | 作为接管前 dirty 基线保护，本轮不编辑、不删除、不纳入提交 | 恢复本轮文件列表，确认该文件仍保持接管前状态 |
| 为满足注释比例导致配置文件膨胀或超过后端 500 行 | 可维护性下降 | 注释解释配置分层和安全原因；接近 500 行时按职责拆配置 Schema/映射模块 | 回退无必要拆分，保留最小强类型入口和测试 |
| 没有取得远端写入或服务启停授权 | 不能完成真实发布/启动验收 | 将 T-04 与代码任务分离，状态明确阻塞，绝不把静态检查当发布成功 | 无外部变更可回退；保留代码可发布成果，等待授权 |
