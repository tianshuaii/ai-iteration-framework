# 测试用例

前置：已取得单独的迁移执行授权；已完成线上测试 Schema 备份；本轮迁移在隔离恢复副本完成演练。

## TC-01 Schema 范围与历史表清理

1. 读取目标库、目标 Schema 和两张迁移元数据表。
2. 执行迁移后按删除清单查询 23 张历史业务/配置表。

期望：只影响 `public_management`；两张迁移元数据表存在；候选历史表不存在。

## TC-02 未使用判定复核

1. 对删除表和字段运行源码、Prisma、外键与运行引用清单核对。
2. 对四个有效服务和四个有效接口项目运行反向保留清单核对。

期望：每个删除对象有无引用证据；每个保留对象有有效运行或版本管理依据。

## TC-03 `yn=0` 物理清理

1. 对所有保留且含 `yn` 的表统计 `yn=0`。
2. 对外键约束和 orphan 记录运行一致性查询。

期望：`yn=0` 计数均为零；无违反约束或孤儿记录。

## TC-04 已删除服务及包清理

1. 查询服务、activation、运行包、运行包 Item 与 Blob 引用。
2. 按删除服务编码和 `yn=0` 包集验证无残留。

期望：删除服务和失效包不存在；共享 Blob 仅在没有任何保留引用时删除。

## TC-05 有效服务运行包保留

1. 读取每个有效服务/环境的 active 和 previous 包。
2. 对运行包表和 Item 表执行保留集合检查。

期望：只保留 active/previous；28 个未引用历史包不再存在。

## TC-06 接口项目历史清理与保留

1. 查询项目、分支、提交、Tree Item、工作区和包记录。
2. 分别核对 `yn=0` 与 `yn=1` 项目。

期望：30 个删除项目及依赖不存在；4 个有效项目仍可读完整历史。

## TC-07 字段与 Prisma 同步

1. 查询 `sys_sub_service` 最终列集。
2. 在三个后端执行 Prisma 生成与定向查询测试。

期望：不含 `service_kind`；不存在 SSO 旧字段声明导致的缺列访问。

## TC-08 备份恢复演练

1. 在隔离恢复副本执行备份恢复。
2. 比对恢复前后的 Schema、行数与关键 active/previous 关系。

期望：恢复可用且与备份清单一致。

## TC-09 有效运行链路回归

1. 使用现有超级管理员会话查询 BFF 服务/运行包和接口项目。
2. 执行接口转发的无副作用错误路径、SSO 登录和 Admin 账户查询。

期望：当前有效能力正常，未出现缺表、缺列、运行包或路由解析错误。

## 受控浅功能回归用例

## SR-01 运行包与转发

前置：有效服务的 active/previous 包已记录。

步骤：查询活动包、前一包和对应接口清单；对已知安全接口发起查询型请求。

期望：包与接口可解析，BFF 不报“接口不存在于已同步文档”。

## SR-02 登录与账户治理

前置：使用既有超级管理员账号，不修改其密码。

步骤：登录，查询账户；对不存在账户提交重置密码请求。

期望：登录和查询成功；重置请求抵达服务端并返回“账号不存在”，而非 Schema 或转发错误。
