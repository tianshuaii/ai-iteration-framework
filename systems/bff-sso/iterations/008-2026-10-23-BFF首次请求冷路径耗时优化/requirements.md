# 需求与注意事项：BFF 首次请求冷路径耗时优化

范围见 [change-scope](./change-scope.md)。验收见 [acceptance](./acceptance.md)。当前进度只看 [status](./status.md)。

## 背景

第 007 轮以本机 BFF 和固定响应的假上游压测，四条路径各记录一次“冷的第一次”：白名单直通 102 ms、需登录直通 83 ms、`POST /proxy/one` 283 ms、单子请求 `POST /proxy/batch` 447 ms。单次观察既不能计算首次请求 P95，也不能证明冷启动条件一致。第 005 轮另一次重启后的直通首请求，打上游前为 1416 ms；预热后 200 次请求的打上游前 P95 为 87 ms。两轮测法不同，不能直接对照。

用户截图中另一条直通 `GET /proxy/mma/user/code` 整体 3587 ms，“查生效包”至“匹配原接口”之间的待归因区间为 3326 ms。接口清单冷载入是线索，但现有记录不足以把这 3326 ms 全归因于数据库、Redis 或单个函数；此路由也不等于第 007 轮测试路由。

本机开发环境的只读定位（2026-10-23）：从该截图对应的 Redis 原始日志复核到 3326 ms 区间；源码显示此区间在 `routeSets` 未命中时等待 `RuntimePackageInventoryService.getInventory` 读取完整运行包。对当前生效包独立读取 3 次为 482/248/336 ms，均执行 6 次数据库查询，查询耗时合计 458/227/312 ms；这证明当前包的清单读取主要花在数据库往返，但不是截图所用包的同条件复现，不能把截图的 3326 ms 全归到数据库。当前直通已有缓存的 3 次低频请求，服务端整段为 397/116/112 ms，清单匹配均约 0–1 ms；首个请求的冷触发条件不明，不能算冷启动样本。

单发和批量共用的 `RuntimeInterfaceResolver` 只合并同时进行的加载，不保留进程内解析结果；默认包解析会读 Redis 中整份物化上下文。当前包 Redis 正文约 504 KB，独立读取加解析 3 次为 426/218/218 ms，其中 Redis GET 为 418/214/212 ms。这支持“每次大对象读取可能拖慢单发/批量”的定位方向，但还未获得两条路径完整、重复的首次请求分段数据。

本机开发环境补充定位（2026-10-23 18:18–18:22）：使用固定响应的本机替身上游，三次分别重启 BFF 后，第一条白名单直通的服务端整段为 417/441/435 ms，客户端整段约 420/443/438 ms，全部成功。对应日志分段“查生效包”119/105/85 ms，“匹配原接口”274/300/327 ms，后者含未命中进程内 `routeSets` 时的整包清单读取，是本组样本最大的可重复冷段；现有事件没有把它继续细分到具体数据库查询。三次样本只能用于定位，不能据此给出可靠 P95 或验收阈值。浏览器登录态下，单发、批量在重启前各一次固定响应探测成功，服务端整段为 652/818 ms；需登录直通服务端成功 192 ms，但这三次均非各路径独立冷启动样本，不计入冷基线。原直连地址已在同轮恢复并刷新页面核对，BFF 健康为 UP；未清 Redis、切包或改产品源码。

本机开发环境补充定位（2026-10-23 18:32–18:39）：在同一固定响应的本机替身上游下，需登录直通、单发、单子请求批量各做 3 次独立 BFF 进程重启，每次 `/health` 就绪后只发送该路径的一条业务请求。需登录直通 `GET /abTestExperiment/getVersionNameList` 服务端整段为 607/863/547 ms，运行包查询 125/117/107 ms，接口清单匹配 328/334/350 ms，会话校验 105/374/53 ms；其中第二次的会话段有明显波动。单发 `POST /proxy/one` 整段为 663/1779/455 ms，入站至首个业务 Span 为 189/1132/101 ms，`forward.input` 至 `forward.response` 为 474/483/354 ms。批量 `POST /proxy/batch` 整段为 461/554/830 ms，入站至首个业务 Span 为 73/120/178 ms，转发 Span 为 387/433/330 ms。单发第二次、批量第三次的首个业务 Span 前出现 gRPC 账号上下文调用；源码表明 `ProxySessionGuard` 会读取 Redis Session、查询账号状态并按到期条件刷新 `ForwardContext`，但现有日志尚不能把前置间隔逐步拆清。单发/批量转发 Span 内混有服务查询、整份运行包解析、目标查询、固定上游响应和审计写入，不能将整个 Span 直接归因于 Redis。固定上游返回均为成功，单发/批量浏览器读回 `200` 且命中替身正文；需登录直通的浏览器读取受跨端口 CORS 限制，但 BFF 日志记为成功。

上述 3×4 组是定位样本，不是验收基线：`/health` 只证明服务可用，不证明异步运行包预热已经结束；浏览器跨端口授权调用可能先发生 CORS 预检；登录 Session 是否恰逢上下文刷新也未固定。因此只能表述为“重启后第一条业务请求”，不能表述为“进程收到的第一条 HTTP 请求”或严格相同的缓存冷条件，不能计算可靠 P95。完整验收前需为预热完成、预检、Session 刷新与冷缓存状态补充可复核标记，再按相同条件扩充样本。测试服务原直连已再次恢复并刷新页面核对，替身已停止，BFF `/health` 为 200；未清 Redis、切包或改产品源码。

## 本次要做

### 页面

- 不新增页面需求，不改请求查询页的筛选、表格、详情和耗时显示口径。定位证据留在本轮测试记录；若现有日志不足，先补 BFF 内部分段计时，需改页面时先回规格阶段扩围。

### 接口与保存

- 将白名单直通 `GET /user/code`、需登录直通 `GET /abTestExperiment/getVersionNameList`、`POST /proxy/one` 转发 `GET /user/code`、`POST /proxy/batch` 内含一条 `GET /user/code`，分别列为首次请求优化对象。批量单子请求用于与第 007 轮对照，多子请求仍须回归正确性。
- 主验收场景是本机 BFF `/health` 就绪后的第一条业务请求，不额外等待异步运行包预热；四条路径分别在独立重启后至少取得 30 个有效样本。记录预热状态、浏览器预检、环境、代码及包版本、BFF 入站至上游发起、上游耗时、整体耗时及 P50/P95/极值。Session 授权上下文到期刷新单独分组，报告耗时与原因，暂不设硬阈值；运行包切换、缓存未命中与长时间空闲仅在获准且可控时另行采样，不与重启样本合并。
- 直通分段定位查生效包、接口清单读取/匹配、会话校验、接入服务和目标地址查询；单发与批量继续拆开业务 Span 前的守卫/Session 刷新，以及 Span 内的服务查询、运行包与缓存解析、接口解析、上游请求、审计写入和批量聚合。数据库、Redis、序列化、连接等待和并发排队均只是候选原因，须用数据证实。
- 只优化重复样本证实的 BFF 冷路径瓶颈，并复测四条路径。用户已确认本机固定上游、无 Session 上下文到期刷新主组的暂定目标：白名单直通整体 P95≤200 ms；需登录直通、单发、单子请求批量各自整体 P95≤350 ms；每路至少 30 次独立重启样本。未完成同条件复测前不得宣称达标；刷新组单独报告，不以主组阈值掩盖它的波动。
- 保持 URL、字段、鉴权、原接口匹配、上游透传、单发响应信封、批量逐项 `requestId` 对应与错误隔离、显式 `packageId` 选包规则不变；不能为了提速跳过安全检查或审计。

### 数据

- 不新增或迁移表，不改既有运行包、白名单、接入服务地址和会话。缓存优化必须保持激活、回滚、归档与跨实例失效后的正确性，不放行过期接口或权限。
- 样本和报告只留脱敏的计时、版本、状态，不留请求正文、Token、密钥、用户数据或目标地址。

## 默认与老数据

| 场景 | 行为 |
|---|---|
| 新建或导入运行包 | 原有导入、激活与首次调用语义不变；预热失败仍走安全校验，不放行未知接口。 |
| 已有运行包与会话 | 不改持久数据；默认生效包、显式 `packageId`、白名单和登录状态沿用原有判定。 |
| 热请求 | 原接口契约不变，不能让已验证热路径明显倒退。 |

## 不做

- 不新增业务接口、页面功能或权限；不强制把单发、批量改成直通。
- 不把第 007 轮假上游吞吐量当线上容量，也不以单个“冷的第一次”推出 P95。
- 不对真实业务服务阶梯加压；本轮仅已获准短时重启本机 BFF、临时改测试服务直连地址并在同轮恢复。未另行授权不清 Redis、不切包、不重启其他服务、不部署。

## 注意事项

- 文件列表见改动范围。当前只做 `specify`；产品文件需到后续 `implement` 阶段，在工作区和资源隔离、逐文件接管记录完成后修改。
- 用户先要求“先定位，再定数值”，在 3×4 个探索样本与阶段归因后确认了上述暂定目标；第 005 轮热路径 P95≤100 ms 和第 007 轮四个单点值均不是本轮冷路径承诺。
