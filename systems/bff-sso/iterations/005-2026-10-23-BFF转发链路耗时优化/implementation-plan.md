# 实现计划

## 目标与测量顺序

先让运行中的 BFF 在 HTTP 入站、完成请求解析、查生效包、读取并匹配原接口、会话校验、查接入服务、解析目标、发起上游请求及响应结束处留下明确边界。用单调时钟计算区间，日志只写阶段名与耗时，不写请求正文、Token、目标地址或凭证。`http.body` 仅表示请求解析到达该钩子，不再据此断言下一段时间都在读取请求体。列表的子请求耗时与详情的整条 BFF 耗时保持原字段，新增的内部耗时只作诊断和验收口径。

先在同一测试环境、同一白名单 GET 接口，对实际运行版本采集优化前基线，再做路由热路径优化。正式对照固定 BFF 和上游版本、接口、直连模式、请求头、负载与时段；每组先预热 10 次，再以并发 1 连续采集至少 200 次，记录完整 Trace 数、P50/P95、冷启动首次请求、上游耗时、异常样本和日志缺口。独立客户端耗时用于交叉检查，不能替代 BFF 内部计时。若测试环境或服务启停未获授权，保留原 4 条 Trace 为定位证据，基线标为未测，不进入“目标已达成”的结论。

## 数据与热路径

不加治理表字段、不迁移。运行包的原接口集合是导入时物化的快照；当前导入逻辑对同 digest 仅允许更新描述，不改接口 blob。直通请求仍逐次查询生效关系、`imported` 状态与白名单，再查当前接入服务；这些可变数据不放进进程缓存，避免切包、撤销白名单或变更直连地址后继续使用旧值。

只在 `HttpPassthroughService` 内对当前生效运行包的数据库主键建立进程内原接口方法/路径集合。首次命中仍用现有 `RuntimePackageInventoryService.getInventory` 构建集合；同包并发冷请求共享一个加载 Promise，失败时移除，不做“查不到就放行”。后续请求命中集合后不再读取三层 blob，也不读取现有约 0.5 MB 的 Redis 上下文。每次查生效关系时淘汰不再处于生效集合的旧包条目，使缓存容量随当前生效包数有界；切到新包 ID 必须重新加载。白名单和当前服务地址保持逐请求读取，非白名单继续走既有 `ProxySessionGuard`。若实现时发现运行包接口行存在原地修改入口，先停在计划阶段重审失效方案，不把包 ID 当成不可变版本。

这层是唯一的 HTTP 直通原接口判定入口，`/proxy/one`、`/proxy/batch` 不经过它；不把缓存逻辑散落到页面、SSO 或每个调用方。若轻量数据库查询和目标解析在优化后仍使 P95 超过 100 ms，按新分段证据重新规划下一瓶颈，不盲目缓存生效关系、白名单或地址。

## 日志与页面

核实原始响应流绕开 Fastify `onSend` 的情况。完整性判定对普通响应仍要求 `http.response`；对直通原始流，仅在结束事件及序号连续、无显式丢弃标记时才视为完整，不能单凭 `forward.response` 就掩盖尾部缺失。历史日志无新增阶段时仍能读取，但不被误认为已做精细分段。

请求查询列表把“耗时”标为“子请求耗时”，详情标为“BFF 整条请求耗时”；时间轴把相邻事件间隔称为待归因区间，只有来自真实开始/结束边界的段才使用确定的阶段名称。不完整记录显示不能用于性能基线。页面不增加筛选项或新业务能力，接口字段暂不改变。

## 验收门槛与回退

实现任务每条先跑定向检查，再做 code review、修复及复验后勾选。最终进入 `verify` 后复跑同条件样本，只有完整样本的“BFF HTTP 入站至发起上游请求前”预热后 P95 ≤ 100 ms 才通过 AC-03；同时报告 P50/P95、样本量和冷路径。功能回归覆盖白名单/登录、未知接口、切包与回滚、流式响应、单发/批量及日志采集故障。

若缓存行为异常，先停止使用新缓存路径，恢复原来的逐请求 `getInventory` 判定并复验；已部署环境回退到上一可用构建由用户另行授权。不能通过跳过接口匹配、鉴权或日志来换性能。

## 字段变化

T-01 没有改外部接口路径和请求、响应字段，也没有改治理表。请求日志里多了内部阶段，旧记录仍按原字段读。

| 字段或路径 | 谁在用 | 变化 |
|---|---|---|
| `/proxy/:publicPath/*` | HTTP 直通调用方 | 路径与语义不变。 |
| 请求日志阶段事件 | BFF 请求查询页 | 直通增加 `passthrough.package`、`match`、`session`、`service`、`target`、`upstream`、`response`。`upstream` 的耗时从 HTTP 入站算到打上游之前。这些事件不带正文、令牌和上游地址。 |
| 治理表、单发和批量接口 | 现有调用方 | 不变。 |
