# 验收标准

| 编号 | 对应测试 | 标准 | 结果 |
|---|---|---|---|
| AC-01 | TC-01 | 两个登录页都是左边约四成宽、三句短话，右边白卡片。底色浅灰，按钮近黑。标题仍分别是网关管理和账号权限管理。 | 通过 |
| AC-02 | TC-02 | 网关左栏三句覆盖接入服务、接口文档、日志，以及仅超级管理员可登录。不再出现「子服务与 OpenAPI」。 | 通过 |
| AC-03 | TC-03 | 账号权限左栏仍说明超管或普通管理员可登录，租户管理员由上级代管。 | 通过 |
| AC-04 | TC-04 | 两个登录判断函数不改。不要求再用普通管理员登录。 | 通过 |
| AC-05 | TC-05 | 登录后侧栏是白的，当前菜单用已有的蓝标出。抽查的列表页页头是左边页面名、右边主要按钮。表格不贴边。 | 通过 |
| AC-06 | TC-06 | 请求查询的耗时列、详情耗时、时间线阶段名、记录不完整提示保持第 005 轮的原文。 | 通过 |
| AC-07 | TC-07 | 网关和账号权限各自每个菜单组至少打开一页，排法一致。网关概览第一张卡片是「接入服务」。菜单项不增不减。 | 通过 |

结果通常使用“未测”“通过”或“未通过”。只有用户明确确认接受未验证项或残余风险时，才写 `豁免：用户确认……；残余风险……`。
