# 需求与注意事项：平台无登录接口与 BFF 加密登录

范围见 [change-scope](./change-scope.md)。验收见 [acceptance](./acceptance.md)。当前进度只看 [status](./status.md)。

## 背景

当前接入平台必须选择登录子服务和登录接口。平台登录成功后，BFF 根据上游返回的 `data.userId` 查找平台账号绑定，创建带 `accessPlatformId` 与 `platformAccountId` 的 Portal Session；非白名单转发同时注入 `X-BFF-Secret` 和 `X-BFF-User-Id`。

部分平台本身没有登录能力，需要复用 BFF 原生账号登录。与此同时，现有两个 BFF 登录入口仍接收明文 `password`，浏览器到 BFF、BFF 到 SSO 的登录协议需要改成不传明文密码的加密协议。

## 本次要做

### 页面

- 接入平台新增、编辑弹窗允许不选择登录接口；无登录接口时，登录接口所在子服务也不作为必填项。
- 接入平台列表能明确区分“平台自有登录”和“使用 BFF 登录”，不能把无登录接口显示成配置失效。
- BFF 管理端和账号权限管理端登录页在提交前使用服务端公开密钥加密密码，请求体不出现明文密码。
- 其他需要接入 BFF 原生登录的平台前端是否纳入本轮，等待 Q3 确认。

### 接口与保存

- 接入平台创建、编辑接口允许 `loginSubServiceId`、`loginInterfaceKey` 及相关快照字段成组为空；只允许“完整登录配置”或“全部为空”，不接受半套配置。
- BFF 原生登录接口新增可选平台字段。未传平台字段时保持平台内建登录语义；传入无自有登录接口的平台时，使用 BFF/SSO 账号密码校验并创建该平台的 Portal Session。
- 平台字段使用 `accessPlatformId`；传入已有自有登录接口的平台时拒绝 BFF 原生登录并提示使用平台登录接口。
- 无自有登录接口的平台 Session 在访问非白名单接口时，只注入 `X-BFF-Secret`，不注入 `X-BFF-User-Id`；有自有登录接口的平台继续注入两项请求头。
- 两个 BFF 登录接口只接受 `keyId + encryptedPassword`，拒绝明文 `password`；两个管理端前端同步升级。
- 登录密文由 BFF 原样转发到 SSO，私钥仅在 SSO；基础算法使用 `RSA-OAEP-256`。
- 加密载荷包含 `password + issuedAt + nonce`，有效期 2 分钟；Redis 保证 nonce 单次使用；密钥环按 `keyId` 管理，上一把私钥轮换宽限 10 分钟。
- 加密信封、Redis 故障策略和公钥获取协议等待 Q6～Q8 确认。

### 数据

- `sys_access_platform` 的登录子服务、登录接口类型、稳定键和快照字段需要支持空值；治理表迁移只在 `adx-admin-backend` 执行，BFF 同步 Prisma 模型。
- 既有平台登录配置原样保留，不自动改为 BFF 登录。
- 无自有登录接口的平台不要求建立平台账号绑定；BFF Session 记录 `accessPlatformId`，但不记录 `platformAccountId`。
- 登录私钥不得写入数据库、前端代码、日志或接口响应；由 SSO 从 Nacos/进程密钥配置读取。

## 默认与老数据

| 场景 | 行为 |
|---|---|
| 新建平台未选登录接口 | 保存为“使用 BFF 登录”，登录配置字段成组为空 |
| 新建平台选择登录接口 | 保持现有平台登录接管与账号绑定逻辑 |
| 已有平台 | 保留原登录配置、绑定与转发行为，不自动迁移 |
| BFF 登录未传平台字段 | 按平台内建服务登录，不绑定接入平台 |
| BFF 登录传入无自有登录接口的平台 | 校验 BFF 账号并创建带平台归属、无平台账号 ID 的 Portal Session |
| BFF 登录传入有自有登录接口的平台 | 拒绝并提示使用平台登录接口 |

## 不做

- 不改变已有平台自有登录接口的 `code/data.userId` 接管协议。
- 不改变 BFF 账号与平台账号绑定唯一性规则。
- 不把登录密码加密范围自动扩大到修改密码、重置密码和 Nacos 登录等其他密码协议；是否另开后续迭代评估。
- 不在本轮提交、推送、部署、执行迁移、写入 Nacos 或启动服务。

## 注意事项

- 本轮涉及接口、数据库、安全权限和多仓库，使用 `strict` 工作流。
- RSA 等不对称加密不能代替 HTTPS；生产环境仍必须使用 TLS。
- 文件列表见改动范围，这里不重复贴路径。
